## Описание
Проект представляет собой мини приложение магазина газет и журналов написанное на языке Dart. 
В ходе разработки были реализованы:
- Поиск газет и журналов
- Расчет стоимости покупки
- Возможность добавления продуктов в корзину и избранное
- Поиск по цене (диапазон 0 - 1000 рублей)
- Вход по логину и паролю

## Технологии
- **Язык:** Dart 3.x
- **Среда разработки:** dartpad.dev

## Как запустить
Для запуска проекта вам понадобится установленный [Dart SDK](https://dart.dev/get-dart) или сайт dartpad.dev
